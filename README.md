# Project Overview

Todo26 is a task management app build with Angular 20, .NET 10 and SQL Server 2025. Todo26 is a laboratory for the integration of this technology stack, specifically to ensure it remains viable and optimal with the latest tech versions. Todo26 includes use of the dotnet CLI and Entity Framework.
